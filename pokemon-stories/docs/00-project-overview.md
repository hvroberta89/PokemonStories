# Pokémon Stories

AI assisted storytelling platform for Pokémon tabletop RPG campaigns.

## Goal

The application helps Game Masters design adventures,
run live sessions and create physical memories.

The application never replaces the Game Master.

## Main principles

- Story First
- AI Companion
- Physical First
- Mobile First
- Offline Friendly
- DDD
- Vertical Slice Architecture
